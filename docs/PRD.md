# PRD — Finance Control v10.2.6

## Продукт

Мобільний **офлайн-first** облік особистих фінансів з прямими інтеграціями банків/брокера. Без власного бекенду.

## Цінність

- Один додаток для Monobank / IBKR / Zen / Privat виписок
- Аналітика та планер на пристрої
- Приватність: дані локально, токени в Secure Store

## Функціональні блоки (реалізовано)

1. Рахунки та баланси  
2. Транзакції + фільтри + деталі  
3. Категорії та правила (включно з автотегами)  
4. Планер доходів/витрат  
5. Аналітика (періоди, KPI, графіки, IBKR holdings)  
6. Імпорт CSV/XLS і API-синк  
7. Теми / акцент / анімації / підписи табів  
8. Біометричний замок  

## Нецілі цієї версії

- Хмарна синхронізація між пристроями  
- Спільні сімейні бюджети  
- Публікація в Google Play / App Store (APK для sideload — так)

## Метрики якості UX

- 60fps motion (Reanimated)  
- Уніфіковані контури / радіуси  
- Попапи ≤ 75% висоти екрана над tab bar
